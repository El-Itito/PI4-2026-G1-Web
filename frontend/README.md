# Lab Catarina Domingos — BackOffice

Frontend do BackOffice do laboratório de prótese dentária, desenvolvido com Next.js, React e TypeScript. O projeto inclui a estrutura visual inicial do painel; ainda não está ligado a backend ou base de dados.

## Iniciar em desenvolvimento

Instala as dependências e inicia o servidor:

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) no navegador.

## Estrutura

- `src/app/`: páginas e estilos globais.
- `src/components/admin/`: layout reutilizável, barra lateral e barra superior.
